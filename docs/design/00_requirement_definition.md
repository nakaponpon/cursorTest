# 要件定義書

## 1. プロジェクト概要
- プロジェクト名：帳票管理システム
- 開発期間：2024年6月～
- 開発環境：React 18 + TypeScript

## 2. 機能要件

### 2.1 認証機能
- [x] ログイン機能
  - ユーザー名/パスワードによる認証
  - セッション管理
  - ログアウト機能

### 2.2 帳票管理機能
- [x] 見積書
  - 見積書の作成・表示
  - 印刷機能（印刷ボタンによる手動印刷）
  - 印刷時の印刷ボタン非表示

- [x] 注文書
  - 注文書の作成・表示
  - 印刷機能（印刷ボタンによる手動印刷）
  - 印刷時の印刷ボタン非表示

- [x] 請求書
  - 請求書の作成・表示
  - 印刷機能（印刷ボタンによる手動印刷）
  - 印刷時の印刷ボタン非表示

- [x] 領収書
  - 領収書の作成・表示
  - 印刷機能（印刷ボタンによる手動印刷）
  - 印刷時の印刷ボタン非表示

- [x] 納品書
  - 納品書の作成・表示
  - 印刷機能（印刷ボタンによる手動印刷）
  - 印刷時の印刷ボタン非表示

### 2.3 設定機能
- [ ] 会社情報設定
  - 会社名
  - 住所
  - 電話番号
  - 銀行口座情報

- [ ] テンプレート設定
  - 各帳票のテンプレート管理
  - カスタマイズ機能
