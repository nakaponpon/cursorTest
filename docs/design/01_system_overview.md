# システム概要

## 1. システム構成

### 1.1 全体構成
- フロントエンド: React + TypeScript
- バックエンド: Node.js + Express + TypeScript
- データベース: PostgreSQL
- ORM: Prisma

### 1.2 ディレクトリ構造
```
.
├── src/                    # フロントエンド
│   ├── components/        # Reactコンポーネント
│   ├── features/         # Reduxスライス
│   └── __tests__/       # テストファイル
├── backend/              # バックエンド
│   ├── src/
│   │   ├── routes/      # APIルート
│   │   └── __tests__/   # テストファイル
│   └── prisma/          # データベーススキーマ
└── docs/                # ドキュメント
    └── design/         # 設計ドキュメント
```

## 2. 主要機能

### 2.1 認証機能
- ログイン機能
  - メールアドレスとパスワードによる認証
  - JWTトークンによるセッション管理
  - エラーハンドリングとバリデーション

### 2.2 データベース設計
- ユーザーテーブル
  - id: 主キー
  - email: メールアドレス（ユニーク）
  - password: ハッシュ化されたパスワード
  - name: ユーザー名
