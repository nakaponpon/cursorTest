# 1. システム概要設計書

## 1.1. はじめに

### 1.1.1. 本書の目的
本書は、Reactベースで構築される「業務アプリケーション」のシステム概要設計について記述するものです。
システムの全体像、主要な機能、アーキテクチャ、および非機能要件について定義します。

### 1.1.2. 対象読者
本プロジェクトに関わる開発者、プロジェクトマネージャー、および関係者を対象とします。

## 1.2. 開発の背景と目的
業務プロセスの効率化を目指し、各種帳票の発行・管理を容易にするWebアプリケーションを開発する。

## 3. 機能要件
(このシステムが提供する主要な機能をリストアップします)

- **F-001: ユーザー状態管理の雛形**
  - Redux Toolkit (`userSlice`) によるログイン状態とユーザー名の保持。
  - (現時点では実際のログイン処理は未実装)
- **F-002: ダッシュボード機能**
  - アプリケーションのメイン画面。
  - 各種帳票印刷機能への導線を提供する。
- **F-003: 帳票印刷機能**
  - 各種帳票を別ウィンドウで表示し、ブラウザの印刷ダイアログを呼び出す機能。
  - **対象帳票:**
    - 請求書 (`/invoice`)
    - 納品書 (`/delivery-note`)
    - 見積書 (`/quotation`)
    - 領収書 (`/receipt`)
    - 注文書 (`/purchase-order`)
