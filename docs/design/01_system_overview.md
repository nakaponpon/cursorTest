# システム概要書

## 1. システム構成

### 1.1 アーキテクチャ
- フロントエンド: React 18 + TypeScript
- UIフレームワーク: Material-UI
- 状態管理: Redux Toolkit
- スタイリング: Material-UIのスタイリングシステム

### 1.2 ディレクトリ構造
```
src/
├── components/          # 共通コンポーネント
│   ├── QuotationPage.tsx
│   ├── PurchaseOrderPage.tsx
│   ├── InvoicePage.tsx
│   ├── ReceiptPage.tsx
│   └── DeliveryNotePage.tsx
├── features/           # Redux関連のコード
├── store/             # Reduxストア設定
└── App.tsx            # アプリケーションのルートコンポーネント
```
